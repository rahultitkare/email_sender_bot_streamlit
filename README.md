# Email Sender Bot - Streamlit Web App 📧

A professional Streamlit-based web application to send personalized bulk emails with attachments using Gmail SMTP.

## 🚀 Features
- Upload recipient CSV
- Personalized email templates using `{name}`
- Plain text + HTML email support
- Multiple attachment upload
- Gmail SMTP integration
- Live progress bar
- Success/failed reports
- Downloadable CSV reports

## 📦 Installation
```bash
pip install -r requirements.txt
streamlit run app.py

# Email Sender  📧

A professional Streamlit-based bulk email automation dashboard with multi-SMTP support, scheduling, template management, database logging, analytics, and attachments.

## 🚀 Features
- Gmail / Outlook / Yahoo / Custom SMTP
- Schedule emails for later
- Save & load templates
- SQLite database logs
- CSV recipient upload & validation
- HTML + Plain text support
- CC / BCC support
- Retry logic + rate limiting
- Live progress and logs
- Success / Failed / Invalid reports
- Analytics dashboard

## 📦 Installation
```bash
pip install -r requirements.txt
streamlit run app.py
