# Email Sender Bot - Streamlit Web App 📧

A professional Streamlit-based web application to send personalized bulk emails with attachments using Gmail SMTP.

## 🚀 Features
- Upload recipient CSV
- Personalized email templates using `{name}`
- Plain text + HTML email support
- Multiple attachment upload
- Gmail SMTP integration
- Live progress bar
- Success/failed reports
- Downloadable CSV reports

## 📦 Installation
```bash
pip install -r requirements.txt
streamlit run app.py
